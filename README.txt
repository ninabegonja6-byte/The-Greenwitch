THE GREENWITCH — STARTER PROTOTYPE

This is a first coded draft of the website's visual direction, not a finished or published site.

HOW TO PREVIEW
1. Unzip the folder.
2. Open the folder in Visual Studio Code (free): https://code.visualstudio.com/
3. Double-click index.html in Finder to preview it in your browser. You can also right-click it and choose Open With > your browser.

FILES
- index.html: page structure and sample content
- styles.css: layout, typography, colors, responsive design
- script.js: JavaScript (currently minimal)

IMPORTANT
- The sample titles and author credits are placeholders, not actual student work.
- The archive dates and issue inventory need to be checked against the physical magazines.
- Before publishing, confirm school approval, rights/permissions for student work and historical scans, and the official submission process.
- This prototype uses no external libraries and does not require a terminal to preview.
